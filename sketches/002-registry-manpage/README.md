## Variante B — Registry / Manpage

### Design stance
La web como terminal/registro de sistema: todo mono, dark-first, prompts y sintaxis de shell. Señal técnica máxima, ejecutada con contención (sin glows ni gradientes).

### Key choices
- Layout: barra TUI arriba, filas tipo registro con bordes, fechas en columna izquierda
- Tipografía: **JetBrains Mono** en todo (incluido display)
- Color: dark-first `#0a0c0b` / texto `#d8d4cc` / verde fósforo `#5ce08a` + ámbar; variante light incluida
- Interacción: filtro de skills funcional con sintaxis `[ todos ]`, toggle tema, cursor blink en el nombre

### Trade-offs
- Strong at: señal de "sysadmin/dev" inconfundible, coherente con su perfil (Control-M, Linux, RPA)
- Weak at: cliché "hacker terminal" si se ejecuta mal; mono para párrafos largos cansa; menos versátil si el CV evoluciona a algo más comercial

### Best for
- CV de perfil técnico puro (sistemas/automatización) que quiere gritar "esto lo hizo un ingeniero de sistemas"
